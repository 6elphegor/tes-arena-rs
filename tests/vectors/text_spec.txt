# The state a text case draws, in order, from its byte stream (the LCG of
# gen_attack.py `stream`), read by harness/gen_text.py and tests/text.rs.
#
#   SEG ADDR KIND [ARGS]
#
# SEG: ds (DGROUP), data (3276), c (CSEG, a scratch segment; the emulator
# relocates it). KIND, and the draws it takes:
#   b N        a byte, (byte) % N
#   w N        a word (low byte, then high), % N
#   d          a dword (four bytes, low first)
#   bc V,..    a byte from the list, by (byte) % count
#   wc V,..    a word from the list, by (byte) % count
#   w2 A B     a word: low (byte) % A, high (byte) % B
#   str N      N characters, each " abcdefghijklmnopqrstuvwxyz"[(byte) % 27],
#              then a NUL
#   bytes N    N bytes
#   seg        CSEG's segment (no draw)
#   text       the text number: (byte) < F0h: a key of POINTER1.DAT by
#              (word) % keys (its low byte for the greetings' keys, 8000h
#              set), else (word) % 700h
#   aim N A:V,..  (byte) < N: each A (hex) written V, a byte (bV) or a
#              word (wV); ADDR is not used
